leaf.loop とは

leaf.loopは、
日常の余白をひらく実験室。

名前の由来は、leaf は葉、loop はめぐり。葉 + ループ。
自然と技術が循環しているようなイメージ。

お茶の温度、宇宙の暗さ、ことばの間合いを、画面の上で確かめています。

体験のしかた

  • タイマーをセットして、眺めるだけでもOK
  • 音は控えめ。必要ならミュートしやすく
  • モバイルでも読みやすい文字幅にしています

プロローグ

忙しい日のあいまに、深呼吸のための小さな間。ことばと色と時間を、静かに並べています。

なぜか早起きした朝、ふと ぽかんと空いた時。
ただ眺めて、「あ、私お茶でもいれようかな」と思える。
そんな“途中”を許す空間を目指しました。
“leaf.loop” は、日常の余白をひらく実験室。

サイト名について

このサイトは、学び直しを目的として制作した ポートフォリオ兼プロジェクトです。

leaf.loopは、葉（leaf）と、ループ（loop）。自然と技術が循環しているようなイメージを持っています。

目指しているのは、五感にやさしい、一枚の静かな体験です。

制作背景・技術

mobile first + progressive enhancement. モバイルを起点に設計し、後方互換を意識することで、どんな端末でも同じ“骨格”の体験ができるよう心がけました。

途中からは AI を“仕事仲間”として迎え、
チェックや提案を受けながら制作を進めています。
ひとりでは難しい部分も、無理なく、スマートに実現できました。

  • HTML / SCSS / JavaScript
  • Figma（設計・検証）
  • Git / GitHub（履歴管理・公開）

担当範囲

すべてのデザイン/実装/検証を一人で行いました。

テーマやモチーフ

お茶でも淹れましょうか。

  • このサイトは、「時間」をひとつの軸に構成しています。 ティータイマーや現在時刻を表示する時計を設置し、 ただ流れる時間を、少し意識できるようにしました。

  • 2ページ目は「世界のお茶」をテーマにしたフォトギャラリー。

  • 3ページ目は「宇宙のことば」。 日常からふっと離れる、心のスイッチとしての言葉を並べています。 操作はほとんど求めません。

  • 「すう〜」ということばを眺めれば、 深呼吸を思い出すかもしれません。
    そんな小さな遊び心も、そっと忍ばせています。

タイマーが止まるまでの間、 世界のお茶や、遠い宇宙のことばに触れてみてください。 その一瞬だけでも、日常の喧騒をふっとカットできたら嬉しいです。
