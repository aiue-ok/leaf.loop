# leaf.loop – A quiet web space for gentle reset — 静かな余白

## 🌱 概要

「忙しい人の午後の時間」に、少しだけ“ひらく”ページ。
操作はほとんど求めない。ただ眺めて、お湯の音や植物の映像に心を預けて、「あ、私お茶でもいれようかな」と思える——そんな”途中感”を許す空間。

画像を眺める体験を中心に置き、装飾や操作を最小限に抑え、静けさ、軽さ、余白のバランスを重視した構造を目指しています。

## 1. 概要

leaf.loopは、ポートフォリオwebサイト作成のためのwebプロジェクト名です。

leaf.loop は、共通のUI基盤をもとに構成された複数のページからなるWebサイトです。モバイルファーストでユーザーに操作を求めないデザイン。各セクションはそれぞれ異なる役割を持ちながら、サイト全体で統一されたビジュアルと言語的トーン、そして一貫したインタラクション設計を保っています。現在も継続的に進化しています。

### ✨ 新規公開

**🍴レシピ**

- `recipe.html`
- `recipes.html`

JavaScriptによるクライアントサイドレンダリング。
動的にDOMを生成して描画。

### 全体像

1. `index.html`（サイト入口）では、主要機能であるタイマーを軸に、gridレイアウトを使い、背景画像内にhoverリンクを設置。ここではハンバーガーメニューはないが、画面内に全てのページへの導線を配置しました。

2. `gallery.html`（「世界のお茶を少しだけ」）は、レスポンシブなgridレイアウト構造とクリックで表示されるLightboxで画像を拡大して閲覧する画像陳列スペースです。画像はwebp/AVIF両対応です。

3. `universe.html`（「遠くのことを少しだけ」）は、ことばと背景レイヤーを時間ごとに切り替えていく紙芝居をイメージしたweb空間です。テーマやことばに応じて背景に変化をつけています。

4. `about.html`（「このサイトについて」）は、このleaf.loopサイトについてテキストです。スクロールや読みやすさを考え、モバイルとデスクトップ用でテキストの分量を変えています。

5. `recipes.html`（「おいしいものを少しだけ」）は、Vanilla JavaScriptを用いたクライアントサイドレンダリングによるレシピアプリです。`data/recipesData.js` をデータソースとして使用。
   URLクエリに基づきデータを取得し、動的にDOMを生成して描画。

---

その他、下記のグローバル UI コンポーネントが導入され、更新されてきました。

- ページナビゲーション用のメニュードロワー
- ミニタイマー
- ミニタイマーの使用をサポートするためのヘルプカード

これらは、サイト全体で一貫した全体的な使いやすさの基盤となります。

`gallery.html`制作時に、これらの UI 基礎を並行して構築しました。

## 2. Features

### 主な機能

- 3分・4分・5分タイマー
- 画像を一覧・拡大できるギャラリー
- 宇宙に関することばを時間で切り替える
- レシピ集、手順詳細ページ
- ページ間で共有されるグローバル 再利用可能な部品
  - ヘッダー、メニュードロワー、ミニタイマー、ヘルプカード、時計など

#### レシピ

- クエリパラメータによる動的ルーティング
- 印刷に最適化されたレイアウト（@media print）
- クリーンなセマンティックHTML構造
- AI生成のレシピ画像（クレジット付き）

#### ギャラリー と ライトボックス

- レスポンシブなグリッドレイアウト
- クリックで開くライトボックス（キャプション表示付き）
- キーボード操作（← → ESC Enter）
- 遅延読み込み（画像の lazy loading）と最適化されたサムネイル

#### ミニタイマー (共通UI)

- コンパクトなクロスページタイマー（ページを超えたカウントダウン"state persistence"未対応）
- モバイル、タブレット、デスクトップ向けのレスポンシブチューニング
- アクセシビリティの高いコントラストのトースト通知
- ミュート機能つきアラームサウンド

#### メニュードロワー (共通UI)

- ページ遷移用のスライドインドロワー
- スクリムと滑らかなアニメーションによる各ページのテーマに沿ったスタイリング
- 現在時刻を取得する飾り時計

#### ヘルプカード (共通UI)

- ミニタイマーの操作説明用
- 控えめオーバーレイデザイン
- ギャラリーやライトボックスのレイヤーとと干渉しない z-index 調整

## 3. 技術スタック と アーキテクチャ

leaf.loop は、Vanilla JavaScript とモジュール化された SCSS によって構築されています。構造・スタイル・レンダリング・機能ロジックを分離し、責務ごとに整理された構成になっています。

---

- HTML / SCSS / JavaScript
- Figma for layout prototypes
- Git & GitHub for version control and deployment
- GitHub Pages for hosting

---

### SCSS 構造

スタイルはレイヤーごとに整理されています。

#### ■ /scss/components

再利用可能なUIコンポーネント：

- `menu-drawer.scss` — ナビゲーションドロワー
- `timer-mini.scss` — 共通ミニタイマー
- `decor-clock.scss` — 装飾時計
- `info.scss` — ヘルプカードなど補助UI
- `scrim.scss` — ドロワー用オーバーレイ
- `page-header.scss` — ページヘッダー
- `_timer.scss` — heroタイマー

#### ■ /scss/core

全体の基盤と共通設定：

- `variables.scss` — 共通SCSS変数
- `base.scss` — CSSカスタムプロパティ（`--tokens`）
- `timer.vars.scss` — タイマー用変数
- `a11y.scss` — アクセシビリティ設定・reduced-motion対応

#### ■ /scss/pages

ページ単位のレイアウト：

- `_hero.scss` — Heroページ
- `_gallery.scss` — ギャラリーレイアウト
- `_universe.scss` — Universeページのエントリーポイント（`@use`のみ）
  - `universe/_index.scss` — モジュール集約（`@forward`）
  - `universe/_tokens.scss` — Universe専用トークン
  - `universe/_animations.scss` — `@keyframes`定義
  - `universe/_base.scss` — ページ構造
  - `universe/_interludes.scss` — 章タイトル
  - `universe/_chapters.scss` — ことば表示
- `_about.scss` — Aboutページ
- `_recipe.scss` — レシピ詳細
- `_recipes.scss` — レシピ一覧

---

### JavaScript モジュール構成

責務ごとに分割されたモジュール設計です。

#### ■ Core

- `site-menu.js` — メニュードロワー制御

#### ■ Data

- `data/creativeLogData.js` — クリエイティブログ用データ
- `data/recipesData.js` — レシピデータ

#### ■ Pages

- `pages/creativeLogPage.js` — クリエイティブログページ
- `pages/recipesPage.js` — レシピページ

#### ■ Rendering

- `render/renderRecipes.js` — レシピ描画処理

#### ■ Features / Effects

- `word_old.js` — Universeページの単語遷移制御
- `gallery.js` — ライトボックス処理
- `timer-base.js` — タイマー基盤ロジック
- `clock.js` — 装飾時計
- `hero.js` — ヒーロー動画制御

## 4. Webパフォーマンス

#### ■ 画像まわりの最適化

- `gallery.html`（世界のお茶を少しだけ）では、最適化された画像フォーマット（AVIF / WebP）と複数のサムネイルバリエーションを使用することで、読み込みコストを削減しています。主要画像には `fetchpriority="high"` を適用することで、体感速度を向上させています。

#### ■ スクリプトは軽量

- ライトボックスとグローバルUIスクリプトは軽量なままで、定義されたアスペクト比と一貫したサイズ設定により、レイアウトのずれを最小限に抑えています。

#### ■ Lighthouse 改善点

- z-indexの改良、未使用のスタイルの削除、画像読み込みの優先度の調整により、Lighthouseスコアが向上しました。

---

## 5. アクセシビリティ

#### ■ Lightbox

- `aria-hidden`, `aria-live`, `role="dialog"` などの Lightbox a11y 設計
- prefers-reduced-motion 対応（過剰アニメを停止）
- キーボード操作の導線（フォーカス処理）
- トースト通知の視認性（緑系の配色理由）
- コントラスト確保

#### ■ トースト / ミニタイマー / メニュードロワー

> トースト通知、ミニタイマー、メニュードロワーは、コントラストを維持し、デバイス間でのレイヤー分けを予測可能にします。

---

## 6. レスポンシブ対応

- Mobile（iPhone SE 実機テスト）
- Tablet（縦 / 横の Mini Timer サイズ調整）
- Desktop（Timer と重ならない padding 追加）
- Surface Duo での特性（幅540pxでの挙動メモ）
- メニュードロワー、ライトボックス、装飾時計、トースト通知は、各ブレークポイント間で一貫性を保ちながらスケールするよう設計されています。
