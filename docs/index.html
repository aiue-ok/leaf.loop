サイトの目的

leaf.loop

自分が好きなキーワード「自然・音・風景・静けさ・制作」から、プロジェクト名を「leaf.loop」と名付け、制作の方向性と位置付けました。

ストーリー

お湯を沸かしましょう。
器を用意して、茶葉をポットやカップに入れて、蒸らし時間が必要であれば タイマーを使ってください。
お茶ができるまでの時間、少しだけ他のページをのぞいてみませんか。

“最初のひと押し”から“公開”まで──制作フロー

* 「leaf.loop」をはじめとした静かな世界観を崩さず、コード学習も兼ねる

* レスポンシブにデザインする

* 途中で AI を“仕事仲間”にする

担当領域

デザインは自分で決めました。

デザイン意図

  • 最初にタイマーへ視線が向くレイアウト
  • 色味をおさえ、余白を活かした静かな空気感
  • 日常の小さな行動（お茶を入れるなど）につながるイメージ選定
  • 繰り返し訪れても迷わず、飽きにくい共通コンポーネント設計

大事にしていること

使う人の目線を大切にしました

アクセシビリティ

  • フォントサイズを16以上に
  • アニメーションがいやな人のために、オフができるよう配慮
  • キーボード操作の際、フォーカス処理を行い、動作を視覚的に
  • コントラストの確保

軽さと素朴さ

  • 見てほしいものに集中させたい
  • シンプルさ
  • 強すぎないそぎ落とし感
  • 現実の時間や行動、視力の使い方・バランス

画像まわりの最適化

  • hero の背景動画は、モバイルでは静止画像表示
  • 動画はサイズを2種類用意し、通信環境により自動で適正サイズを使用するよう設定
  • gallery.htmlでは、表示高速化のため、最適化された画像フォーマット（AVIF / WebP）と複数のサムネイルを準備し、読み込みコストを削減
  • 主要画像には fetchpriority="high" を適用し、体感速度を向上

さらに改善

Lighthouse（googleのウェブページの品質を改善するためのオープンソースの自動化ツール）を利用し、 z-indexの改良、未使用のスタイルの削除、画像読み込みの優先度の調整により、Lighthouseスコアが向上しました。
また、Markup Validation Service を利用して、文法エラーや記述ミスがないかチェックしています。

コンテンツ

レスポンシブデザイン

モバイル・タブレット・デスクトップ、どのブラウザにも対応

静かな設計

各セクションはそれぞれ異なる役割を持ちながら、 サイト全体で統一されたビジュアルと言語的トーン、 そして一貫した 相互作用 設計を保っています。

時間とともに

静けさ主体・気持ちの切り替えを先導しつつ、リアルな時間も同期します。 どのページでもタイマーが表示され、隠しメニューを開くとアナログ時計が表示されます。

サイトの入口

サイトの顔として、お湯を沸かす動画を配置。 主要機能をタイマーとして、 視線の動きを減らし、gridレイアウトですべてのページへの導線を一画面にまとめています。

View more

フォトギャラリー

レスポンシブなgridレイアウトによる画像ギャラリー

世界のお茶を少しだけ

グリッドレイアウトや、モーダルウィンドウなどのコーディングの学習のため、作成。 ”世界のお茶”をテーマに写真を一覧で見せるかたちのギャラリーです。

拡大表示に対応

Lightbox（拡大画像・キャプション表示付き）を実装。 Tabキー、十字キーやEnterで画像の移動、拡大・キャンセルをキーボード操作できます。

画像を軽く（WebP / AVIF）

最初に読み込む画像を1枚に決め、最初はサムネイルを表示。 拡大表示をする際に、ブラウザに合わせWebP / AVIF形式を自動で表示し、軽量化をしました。

コンテンツを邪魔しないよう、スペースやレスポンシブとのデザイン効率を考え、ハンバーガーメニューを置きました。

このヘルプカードは、タイマーの操作方法についての説明を画面上に表示します。モバイル画面では縦向き・横向きに応じて、レイアウトが変化します。各ページのテーマカラーに合わせています。
